# E-Learning Platform (LMS)

## Features
- User Registration & Login
- Course Management
- Enrollment System
- Meeting Scheduling

## Tech Stack
- HTML, CSS
- PHP
- MySQL

## Setup Instructions
1. Install XAMPP
2. Move project to htdocs
3. Create database "edusphere"
4. Import SQL file
5. Run: http://localhost/Edusphere-master/
